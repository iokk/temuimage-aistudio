# TuLite 单管理员账户与统一存储设计

## 目标

在不破坏现有任务、项目、提供商配置和部署数据的前提下，将共享访问密码升级为可管理的单管理员账户，并建立未来扩展多用户、角色权限和对象存储所需的稳定边界。

首个管理员账号为 `admin`，初始密码由部署环境安全注入。当前部署的初始密码为 `hamood1998`。登录会话有效期为 30 天。

## 范围

本阶段包含：

- 单管理员用户名和密码登录。
- 密码哈希、会话、角色、权限和安全审计数据模型。
- 账户设置、修改密码、退出当前会话和退出其他会话。
- 登录失败限速和账户禁用能力。
- 统一数据根目录和存储适配器。
- 现有任务、项目和文件路径的兼容迁移。
- 本地与 1Panel 部署更新。

本阶段不包含：

- 公开注册、邮箱验证和找回密码。
- 多管理员审批、组织、套餐或计费。
- 对象存储管理页面；仅建立可替换接口并保留现有 S3 配置能力。

## 账户模型

用户记录包含：

- `id`：不可变用户标识，也是数据归属键。
- `username`：规范化后唯一，首个用户为 `admin`。
- `password_hash`：单向哈希，不存储或记录明文。
- `role`：当前为 `admin`，以后可增加普通角色。
- `status`：`active` 或 `disabled`。
- `session_version`：密码修改或全局退出时递增，用于立即撤销旧会话。
- `created_at`、`updated_at`、`last_login_at`。

权限使用稳定字符串标识：

- `manage_account`
- `manage_users`
- `manage_providers`
- `submit_tasks`
- `manage_projects`
- `view_audit`

当前管理员拥有全部权限。页面和服务层通过权限检查，而不是直接判断用户名；未来增加角色时无需重写业务入口。

## 身份验证与会话

登录表单收集用户名和密码。密码验证成功后创建随机会话令牌，浏览器只保存令牌，服务端只保存令牌摘要、用户 ID、到期时间、最后活动时间和 `session_version`。

会话默认 30 天过期。以下操作立即使相关会话失效：

- 修改密码：递增 `session_version`，撤销其他会话，并签发当前新会话。
- 退出其他会话：保留当前会话，撤销其余会话。
- 禁用账户：撤销全部会话。
- 主动退出：撤销当前会话。

登录失败按用户名和客户端来源进行短时限速。错误提示不区分“用户不存在”和“密码错误”，日志不记录密码或完整会话令牌。

## 页面设计

未登录用户只看到安静的登录页面：产品名称、用户名、密码和登录按钮，不加载任务、项目、模板或提供商数据。

登录后侧边栏显示当前用户名和角色，并提供“账户设置”和“退出登录”。账户设置包含：

- 修改密码：必须输入当前密码和新密码。
- 查看会话摘要：创建时间、最后活动和到期时间，不展示令牌。
- 退出其他会话。

用户管理入口在当前单用户阶段显示账户状态和角色，但不开放创建第二个用户；底层接口和权限保留，下一阶段可以直接增加用户列表、创建、禁用和重置密码操作。

## 数据归属

认证用户 ID 取代匿名安装工作区作为新任务和项目的 owner。现有无 owner 或旧安装 owner 的数据在首次管理员迁移时归属给 `admin`，迁移必须幂等。

任务、历史项目、个人模板和未来用户配置均通过 `owner_id` 查询。管理员当前只能看到自己的业务数据；未来如需全局管理，必须通过显式管理权限和管理视图实现，不能绕过仓储边界。

## 统一存储

所有持久数据位于一个可配置根目录，默认是 `data/`：

```text
data/
  app/
    identity.sqlite3
    audit.sqlite3
  tasks/
    tasks.sqlite3
  files/
    uploads/
    references/
    results/
    thumbnails/
    exports/
  projects/
  providers/
  logs/
  backups/
```

逻辑对象键采用可迁移格式：

```text
{owner_id}/{project_id}/{task_id}/{item_id}/{filename}
```

业务代码不直接拼接绝对路径，而是调用 `StorageBackend`：

- `put(object_key, source)`
- `open(object_key)`
- `exists(object_key)`
- `delete_prefix(prefix)`
- `local_path(object_key)`，仅本地后端支持
- `download_url(object_key)`，对象存储后端可返回临时链接

默认实现为 `LocalStorageBackend`。现有 S3/兼容对象存储配置迁移到 `S3StorageBackend`，任务和项目层只保存对象键与元数据，不依赖后端绝对路径。

## 兼容与迁移

升级不得移动或删除现有文件。迁移分为两步：

1. 为现有路径生成兼容对象键和索引；读取时先使用新对象键，缺失时回退旧路径。
2. 后台或人工维护动作可将旧文件搬迁到新结构，成功写入索引后才删除旧副本。

SQLite 和 JSON 迁移必须带版本号、事务或原子替换，并可重复执行。升级前备份整个数据根目录，包括 SQLite WAL/SHM 文件。

## 部署配置

新增或规范化环境变量：

- `TULITE_DATA_DIR=/app/data`
- `TULITE_ADMIN_USERNAME=admin`
- `TULITE_ADMIN_PASSWORD`：仅首次初始化使用，初始化后不写回配置文件。
- `TULITE_SESSION_DAYS=30`
- `FILE_STORAGE_TYPE=local|s3`

旧 `APP_ACCESS_PASSWORD` 在一个兼容周期内可作为首次管理员密码来源；身份数据库初始化后不再参与每次登录验证。部署文档明确提醒删除旧共享口令或替换为初始化变量。

## 安全与错误处理

- 使用标准密码哈希实现；参数需要可升级，登录成功时可重新哈希。
- 会话令牌必须来自密码学安全随机数，服务端仅存摘要。
- 所有账号、密码、权限和存储管理操作写入脱敏审计记录。
- 数据库或密钥初始化失败时拒绝访问，不回退到无认证模式。
- 账户设置和提供商设置执行服务端权限检查，隐藏按钮不是安全边界。
- 不在错误页、日志、任务载荷和审计记录中输出密码、令牌或 API Key。

## 测试边界

公共测试接口包括：

- `IdentityService`：初始化管理员、登录、校验会话、修改密码和撤销会话。
- `AuthorizationService`：按权限允许或拒绝操作。
- `StorageBackend`：对象键写入、读取、存在判断和前缀删除。
- 应用入口：未登录不加载业务页；有效会话进入应用；过期或撤销会话返回登录页。
- 迁移入口：旧 owner 和旧文件路径迁移幂等，失败不删除旧数据。

测试采用逐项红绿循环，并覆盖错误密码、限速、过期会话、密码修改、会话撤销、路径穿越、owner 隔离和部署重启后的持久化。

## 验收标准

- `admin` 可使用部署初始化密码登录。
- 登录状态可维持 30 天，退出和密码修改会按规则撤销会话。
- 未登录用户无法访问任务、项目、提供商或文件数据。
- 所有新文件进入统一数据根目录和规范对象键。
- 现有项目和任务升级后仍可访问，不发生数据删除。
- 本地和 1Panel 部署通过登录、任务提交、结果归档、重启持久化和备份恢复烟测。
- 全量自动测试、部署清单和安全脱敏测试通过。
