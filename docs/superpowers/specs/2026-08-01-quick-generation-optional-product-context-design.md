# 快速出图可选商品上下文设计

## 目标

让“快速出图”的参考图片成为商品识别的默认依据。用户不应因为没有填写商品名称而无法提交任务；当商品型号、品类或创作要求需要补充时，用户可以提供可选文字上下文。

## 现状与结论

当前后台任务在收到参考图片后已经调用 `analyze_product()` 进行视觉识别，并且空商品名称存在安全的默认值。阻止无名称任务的唯一位置是页面上的创意出图提交条件。因此产品名称并不是执行该工作流的必要输入。

## 输入与提交规则

1. 参考图片仍为必填项。
2. 创意出图仍至少需要选择一个出图类型。
3. 图片翻译沿用现有规则：仅要求参考图片。
4. 商品名称、材质和补充提示词均为可选项。
5. 不填写商品名称时，任务摘要使用“未命名项目”，后台继续使用参考图片做商品识别。

## 提示词优先级

1. 参考图片定义商品的形状、颜色、材质、品牌标识和基本外观。
2. 可选商品名称与材质只作为识别辅助信息。
3. 补充提示词用于本次生成的场景、构图、卖点或文案偏好，并会附加到每一张生成图的最终提示词中。
4. 补充提示词不能取消既有的参考图保真、合规与安全约束；与参考图商品本体冲突时，以参考图为准。

## 页面交互

1. 将“商品名称 *”改为“商品名称（可选）”，并说明不填时由 AI 根据商品图识别。
2. 将“材质”明确为可选。
3. 新增“补充提示词（可选）”多行输入，说明它会影响本次所有出图类型。
4. 提交按钮仅在缺少图片或创意模式未选择出图类型时禁用，不再因商品名称为空禁用。

## 兼容性与验收

已有任务载荷不变可继续执行。新增字段缺失时，最终提示词保持与当前版本一致。

验收条件：

1. 参考图加任一类型、商品名称为空时可以提交创意出图任务。
2. 无图片或没有选择创意出图类型时仍不可提交。
3. 补充提示词为空时最终提示词不发生变化。
4. 补充提示词非空时，每个待生成项目都携带该提示词和参考图保真说明。
