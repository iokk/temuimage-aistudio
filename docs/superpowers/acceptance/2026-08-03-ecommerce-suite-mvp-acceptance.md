# 电商标准套图 MVP 验收记录

验收日期：2026-08-04

## 验收范围

- 1–14 张参考图与 1–10 张输出计划解耦，默认输出 8 张。
- 双阶段工作台：素材和类型设置 → 可编辑计划审核。
- 缺少背面、细节或真实尺寸证据时安全替换，不虚构结构和尺寸。
- 每个计划项固化提示词，并独立选择 1–3 张相关参考图。
- 后台任务持久化、重复提交去重、失败项独立重试。
- 输出统一为 1600×1600、PNG/JPG、单张不超过 2MB。
- 默认无 LOGO，目标语言和文案由用户通过提示词控制。
- 提交失败时仅清理本次新建的上传文件，不影响已有任务或其他文件。
- 计划编辑、复制和删除会生成新的提交版本，避免误复用旧任务。
- 兼容旧版个人模板列表格式，升级后模板仍可见。
