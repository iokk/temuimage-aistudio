# 快速出图可选商品上下文验收

日期：2026-08-01

## 交付范围

“快速出图 / 图片翻译”中的创意出图现在以参考图片为必需上下文；商品名称和材质改为可选辅助信息。用户可以填写可选“补充提示词”，它会进入本次每一张图的最终生成指令。

## 行为验收

| 编号 | 场景 | 验证结果 |
| --- | --- | --- |
| QG-01 | 有参考图和一个出图类型、商品名称为空 | 可提交；名称不是前置条件 |
| QG-02 | 无图片或创意模式未选类型 | 仍不可提交 |
| QG-03 | 商品名称仅包含空格 | 规范化为空，任务摘要显示“AI识图” |
| QG-04 | 非空补充提示词 | 每个生成项目都有用户方向、参考图保真说明和最终合规规则 |
| QG-05 | 风险提示词 | 页面、任务创建入口和执行端均按当前合规模式拒绝，并显示原因 |
| QG-06 | 旧任务缺少 `user_instruction` | 保持旧的最终提示词，不追加新段落 |
| QG-07 | 失败项重试 | 复用已保存最终提示词一次，不重复追加或重新校验已忽略的用户方向 |
| QG-08 | 英文合规词匹配 | `secure ... scene` 可通过；`CE certified`、`FDAapproved` 与 `medicalcure` 仍会被拒绝 |
| QG-09 | 后台任务合规复核 | 使用任务保存的合规用户标识，不访问 Streamlit 会话状态 |

## 页面验收

1. “商品名称（可选）”，占位说明为“不填写时由 AI 根据商品图识别”。

3. “补充提示词（可选）”，带出其参考图保真约束说明。

未发起新的真实出图请求，避免为本次界面和任务链路验收产生额外费用。

## 审查处理

独立代码审查的空白名称与多图覆盖建议已修复。架构审查提出的补充提示词合规绕过风险已通过“页面筛查 + 任务创建入口校验 + 使用保存用户上下文的执行端防御性校验 + 执行末尾合规规则”四层处理，并由多图、旧任务和重试回归测试覆盖。英文合规词按词边界匹配，同时识别相连的禁用词，避免认证缩写误伤正常场景词而不放过拼接声明。

## 剩余边界

补充提示词的风险词判断依赖当前可配置的合规词库；上游图像模型的最终输出仍应按业务需要进行人工复核。
