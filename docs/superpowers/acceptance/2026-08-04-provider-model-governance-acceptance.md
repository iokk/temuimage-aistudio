# Provider Model Governance 验收

## 已实现

- 上游目录同步后，非空目录不再追加内置模型。
- 文字、视觉、出图三个选择器分别按能力筛选。
- 模型能力支持用户覆盖，刷新目录保留覆盖值。
- 旧绑定模型从目录消失时仍可选择并可见。
- 本地预置候选仅在“显示本地兼容候选”开启后出现。
- 任务客户端继续使用既有 `title_model`、`vision_model`、`image_model` 字段和接口。

## 自动验收

专项测试覆盖上游目录隔离、能力覆盖持久化、旧绑定保留、OpenAI/Gemini/Relay 目录解析和 Streamlit 兼容性。发布前运行全量 unittest 与编译检查。

## 安全边界

模型同步只读取目录，不自动执行付费图片能力探测。用户选择的模型会在任务载荷中冻结，重试不会重新推断模型能力。
